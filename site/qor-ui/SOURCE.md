# qor-ui

Shared Qor design system (tokens, motion, nav, footer, brand assets) used by the qortime.com hub and /cap.

Source: QorStream's design package, qorstream PR #38, commit a938667 (design by Gemini Carbon). Copied as plain CSS and ES modules with no build step. footer.js default copy was adjusted for QorTime.

Gold (`--qor-verified`) is only for a referee-VERIFIED match record (`.qor-verified-record`).
