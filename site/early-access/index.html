  1. 01

    Look at a receipt

    Use a match receipt, or load the demo JSON on the verifier. Confirm the id the page reads (receipt id, or else the match id).

  2. 02

    Verify for free

    Run the signature check. VERIFIED means the signed contents hold against the pinned referee key. That result is the one a platform should trust for the score story. It is not a payment.

  3. 03

    Open test checkout

    The button above goes to Stripe’s hosted test Payment Link. You can also start a receipt-tied test Checkout from the verifier. Both are test mode. Canceling records nothing as paid.

  4. 04

    Wait for the test badge

    After a receipt-tied test payment, the verifier asks the test service whether that id is paid. The badge appears only when that lookup says so. If the host has no test key yet, the lookup can come back empty. The local signature check still runs.
