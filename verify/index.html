    What the results mean

    VERIFIED Every signature, checkpoint, and challenge holds against a trusted QorTime referee key. The only result shown in gold.

    PARTIAL Signatures check out against a trusted QorTime referee, but an evidence check is partial or missing (challenge, motion, …). Not a verified result.

    SELF-SIGNED Cryptography holds, but the referee key is not on QorTime's built-in trusted list (local Start Match key, self-hosted key, or revoked). Never shown as VERIFIED. Raw output calls this status SELF_ATTESTED.

    FAIL A signature, checkpoint chain, canonical JSON rule, or challenge check failed.

    Device keys are reported as software or TPM claimed (unverified). TPM claimed is the strongest device status the referee reports and is not hardware identity proof.

    Evidence panels explain the verifier's result. They never decide it.
