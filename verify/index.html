    What the results mean

    VERIFIED — every signature, checkpoint, and challenge holds against a trusted QorTime referee key. The only result shown in gold.

    PARTIAL — signatures check out against a trusted QorTime referee, but something is missing (challenge, motion, …). Not a verified result.

    SELF-SIGNED — cryptography holds, but the referee key is not on QorTime's built-in trusted list (local Start Match key, home-made key, or revoked). Never shown as VERIFIED. The raw output calls this status SELF_ATTESTED.

    FAIL — a signature, the chain, or a challenge does not hold.

    Device keys are reported as software or TPM claimed (unverified). TPM claimed is the strongest device status the referee gives. It is not hardware proof.
