Signature checks run in this browser. The receipt JSON is not uploaded. The Verified Match badge sends only the receipt id to the test checkout service. That badge is TEST / early access until KYC. It is not a live paid product.

VERIFIED — every signature, checkpoint, and challenge holds against the pinned referee key.

PARTIAL — signatures check out against a trusted QorTime referee, but something is missing (challenge, motion, …).

SELF_ATTESTED — cryptography holds, but the referee key is not on QorTime's built-in trusted list (local Start Match key, home-made key, or revoked). Never shown as VERIFIED.

FAIL — a signature, the chain, or a challenge does not hold.

Verified Match test mode

A test payment alone shows a neutral “paid, test mode” tag. Gold appears only when this page’s signature verdict is VERIFIED. The payment does not change that verdict. Live payouts stay off until KYC is done.
